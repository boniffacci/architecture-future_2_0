# Модуль виртуальной машины для Yandex Cloud

Этот модуль Terraform позволяет создавать виртуальные машины в Yandex Cloud с возможностью настройки под разные окружения (dev, stage, prod).

## Описание модуля

Модуль создает:
1. Виртуальную машину с указанными параметрами CPU и RAM
2. Дополнительный диск заданного размера
3. Сетевой интерфейс с подключением к указанной подсети
4. Настройку SSH-доступа

## Параметры модуля

| Параметр    | Тип    | Обязательный | По умолчанию         | Описание                          |
|-------------|--------|--------------|----------------------|-----------------------------------|
| vm_name     | string | Да           | -                    | Имя виртуальной машины            |
| environment | string | Да           | -                    | Окружение (dev, stage, prod)      |
| cpu_count   | number | Нет          | 2                    | Количество ядер CPU               |
| ram_size    | number | Нет          | 4                    | Объем RAM в ГБ                    |
| disk_size   | number | Нет          | 20                   | Размер диска в ГБ                 |
| subnet_id   | string | Да           | -                    | ID подсети                        |
| ssh_key     | string | Да           | -                    | SSH-ключ для доступа              |
| zone        | string | Нет          | "ru-central1-a"      | Зона доступности                  |
| image_id    | string | Нет          | Ubuntu 22.04 LTS     | ID образа ОС                      |
| labels      | map    | Нет          | {}                   | Метки ресурсов                    |

## Выходные значения

| Выход       | Описание                          |
|-------------|-----------------------------------|
| vm_id       | ID виртуальной машины             |
| vm_name     | Имя виртуальной машины            |
| private_ip  | Внутренний IP-адрес               |
| public_ip   | Внешний IP-адрес                  |
| disk_id     | ID дополнительного диска          |
| disk_name   | Имя дополнительного диска         |
| fqdn        | Полное доменное имя               |

2. Настройте провайдер Yandex Cloud
3. Создайте облако, каталог и сетевую инфраструктуру
